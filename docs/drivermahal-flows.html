10. Alert Subscriptions & Notifications

Drivers and Managers subscribe to from→to + radius criteria; the matcher fires on every new trip / vacancy.

Alert Creation

➕
Create Alert
Name, From + radius (default 25km), To + radius (optional, null = "any"), min ₹/km, min commission %, car types, daily window
▼
📡
Notification Channels
Pick: Web Push · in-app · SMS · email
▼
🔘
Pause / Resume / Delete
Anytime from Alerts page

Notification Pipeline

📝
New Trip Posted
Or new vacancy posted
▼
🔄
match_alerts_for_trip()
PG function: from-radius haversine + to-match + rate/commission/car/window filters
▼
📲
Web Push (VAPID)
Service worker · iOS Safari fallback to in-app + SMS
▼
⏱
Rate-limited
Max 1 push per 5 min per alert (anti-spam)
🔔Sample Push: "New trip — Vellore → Chennai · ₹15/km · Sedan AC · pickup in 4h. Tap to view."
